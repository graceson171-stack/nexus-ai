# NEXUS

NEXUS is a long-term AI knowledge and learning engine built from the ground up while learning core Computer Science and AI concepts.

The project starts as a simple document management and keyword search system and will gradually evolve into an AI-powered knowledge system.

## Current Version

v0.1.0

## Current Features

- Add documents
- Delete documents
- List documents
- Persistent JSON storage
- Keyword-based document search
- Case-insensitive search
- Input validation
- Modular Python functions
- Automated testing
