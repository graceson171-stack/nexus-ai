# NEXUS 🧠

NEXUS is a long-term AI engineering project focused on
building an intelligent knowledge and learning system
while learning AI and core Computer Science fundamentals.

## Goals

- Learn AI from fundamentals
- Understand Machine Learning and Deep Learning
- Build NLP and Transformer-based systems
- Implement semantic search and RAG
- Build AI memory and reasoning
- Learn backend and database systems
- Learn software engineering
- Learn deployment and cloud technologies

## Learning Philosophy

Learn → Build → Break → Debug → Understand → Rebuild
